使用帮助

一、加密图片
  1. 在上方算法区选择模式（V3 区域打码为默认）
  2. 点击或拖拽图片到「加密图片」框（支持 Ctrl+V 粘贴）
  3. 如需区域打码：在图上用手指/鼠标框选要保护的区域，可多选，也可以设置全图打码
  4. 输入密码 → 点击加密按钮 → 生成加密图，右下角显示格式与大小
二、解密图片
  1. 切到「解密图片」，载入加密图
  2. 输入同一密码 → 点击还原
  3. 密码错误会提示；若出现「无法读取元数据」，请检查：
    • 图片是否被裁切过
    • 若对方使用无损传输，是否为未压缩的原图
三、V3 参数说明
  • 前置缩放：加密前先把图片缩小，减小输出体积。仅影响输出尺寸，不影响还原
  • 输出格式：100% 为无损 PNG（体积可能增加 3-4 倍，网络传输必须传输原图，否则会造成损坏）；调低会输出 JPEG（体积更小，网络传输不易损坏）。JPEG 输出采用J2 拍屏鲁棒码：边框加宽至 64px，四角 QR 式定位符 + 黑白二值环带码（RS 自适应纠错 + 位级交错），可抵抗二次压缩、均匀缩放与旋转透视（含手机拍屏，建议整图占满画面、避开反光）、部分裁切；PNG 加密不受任何影响。
  • 诱饵图：可选上传一张图片，每个打码区域都会独立铺满显示这张诱饵图（N 个区域 = 这张图出现 N 次）。可能会造成图片尺寸增大
四、关于 / 安全说明
  • 本页所有加密、解密操作均在你自己的设备上完成，图片不会上传到任何服务器
  • 安全性取决于密码强度：请使用足够长、不易被猜到的密码
  • 密码无法找回，丢失即无法解密，请妥善保管
  • 加密后的图片可以自由传输，但若为 PNG 格式需保证传输过程不经过有损压缩（详见上文输出格式说明）
  • 本工具的设计目标是在任意渠道隐匿图片内容，不建议用于任何违法用途
