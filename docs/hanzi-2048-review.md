# 汉字密文 v2 字库（2048）— 人工过目清单

## 生成依据

- **汉字区 1792 字**：GB2312 一级汉字 3755 字为候选池，按 [MTSU 汉语字频表](https://lingua.mtsu.edu/chinese-computing/statistics/char/list.php?Which=HSK)（11115 字排名）降序取前 1792，并剔除 97 个**忌讳/粗俗/文言/生僻**字。
- **符号区 256 个**：常用标点 + 数学 + 货币 + 箭头 + 几何 + 圈号 + 全角数字，补足 2048。
- **总长 2048**（汉 1792 + 符 256），唯一 **2048**，**无重复**。
- 11 bit/字，周期 88bit（8 字 ↔ 11 字节），无位浪费；相对 4096 表长度 +9.1%。

> 序号即编码值：密文首字 = 序号 1，以此类推。**表一旦定稿不可再改顺序**，否则已发密文全部失效。
